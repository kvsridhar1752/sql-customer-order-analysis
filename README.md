# SQL Customer Order Analysis

This project uses SQL to analyze customer orders, revenue, repeat purchasing, customer retention, and product performance.

## Business problem

An online retailer wants to understand which customers generate the most revenue, how often customers return, which products sell best, and where revenue is concentrated.

## Tools used

- SQL
- SQLite
- Python
- pandas

## Dataset

The project creates three related tables:

- `customers`: customer ID, name, city, signup date
- `products`: product ID, product name, category, unit price
- `orders`: order ID, customer ID, product ID, order date, quantity, revenue

The data is synthetic and generated by `data/generate_data.py`.

## Analysis questions

1. What is the total revenue and average order value?
2. Which customers generate the highest revenue?
3. How many customers place more than one order?
4. Which product categories generate the most revenue?
5. Which products are the best sellers by quantity and revenue?
6. How does revenue change by month?
7. What share of revenue comes from repeat customers?

## SQL skills demonstrated

- `SELECT`, `WHERE`, `GROUP BY`, and `ORDER BY`
- `JOIN` across customers, products, and orders
- Aggregations with `SUM`, `COUNT`, and `AVG`
- `CASE WHEN` for customer segmentation
- Common Table Expressions (CTEs)
- Window functions for rankings
- Date-based monthly analysis

## How to run

```bash
pip install -r requirements.txt
python data/generate_data.py
python analysis/run_sql_analysis.py
```

The script creates `retail.db`, runs the SQL analysis, and saves the results to `output/sql_results.csv`.

## Files

- `data/generate_data.py`: creates the SQLite database and synthetic data
- `sql/customer_order_analysis.sql`: contains the main business-analysis queries
- `analysis/run_sql_analysis.py`: runs the SQL queries and exports results
- `requirements.txt`: Python dependencies

## Portfolio value

This project demonstrates practical SQL analysis: joining tables, calculating business KPIs, identifying high-value customers, measuring repeat purchases, and ranking products by performance.
